# CRM Project

This repository contains the frontend and backend for the CRM application.

## Project Structure

- Frontend/vite-project - React + Vite frontend
- Server - Node.js/Express backend

## Requirements

- Node.js
- npm

## Setup

### Frontend

```bash
cd Frontend/vite-project
npm install
npm run dev
```

### Backend

```bash
cd Server
npm install
npm start
```

## Notes

- Make sure the frontend and backend are running for full functionality.
- Update environment variables if required in the respective project folders.
